# Plik karaoke do tekstu

Tu jest plik `.kar` z piosenką (`barka.kar`). Przy budowaniu (`ufbt`)
narzędzie `narzedzia/kar_na_tekst.py` zrobi z niego `pliki/tekst.txt`,
a plik trafi do środka `barka.fap`. Folder `pliki/` to wynik budowania
i jest w `.gitignore`.

Jeśli plików `.kar` jest kilka, używany jest pierwszy alfabetycznie.
