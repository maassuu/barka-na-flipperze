# Plik karaoke do tekstu

Włóż tu plik `.kar` z piosenką (np. `barka.kar`). Przy budowaniu (`ufbt`)
narzędzie `narzedzia/kar_na_tekst.py` zrobi z niego `pliki/tekst.txt`,
a plik trafi do środka `barka.fap`. Zawartość tego folderu (poza tym opisem)
i folder `pliki/` są w `.gitignore` - tekst nie trafia do repo.

Jeśli plików `.kar` jest kilka, używany jest pierwszy alfabetycznie.
